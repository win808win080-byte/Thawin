# Portfolio ของนายธาวิน เดชวัฒน์

เว็บไซต์ Portfolio แบบ static ภาษาไทย สร้างด้วย HTML, CSS และ JavaScript แบ่งเป็น 3 หน้าแยกกัน รองรับหน้าจอมือถือและเดสก์ท็อป

## เปิดใช้งาน

เปิด Terminal ในโฟลเดอร์ `assets` แล้วรัน local server (หน้าแอดมินใช้ JavaScript modules และ IndexedDB):

```powershell
python -m http.server 5500
```

จากนั้นเปิด `http://localhost:5500` โดยแต่ละหน้าจะอยู่ที่:

- `index.html` — หน้าแรก
- `work.html` — ผลงาน
- `about.html` — ประวัติส่วนตัว
- `admin.html` — จัดการ/อัปโหลดผลงาน

## ปรับแต่งหน้าเว็บ

- แก้ชื่อและข้อมูลแนะนำตัว/ประวัติส่วนตัวใน `index.html` หรือ `about.html`
- แก้ข้อมูลผลงานในการ์ด `.project-card` ใน `work.html`
- ปรับสีและการจัดวางใน `style.css`
- แบนเนอร์แนวนอนด้านบนหน้าแรกใช้ไฟล์ `รูป/รูปโปร.png` โดยกำหนด `src` ของ `.home-banner img` ใน `index.html`
- ภาพในกรอบโปรไฟล์ใช้ไฟล์ `รูป/เอง.jpg` ทั้งหน้าแรกและหน้าประวัติส่วนตัว หากเปลี่ยนรูป ให้อัปเดต `src` ของ `.avatar-art img` ใน `index.html` และ `about.html` โดยกำหนดตำแหน่งครอปใน `style.css`

## หน้าแอดมินและการเผยแพร่ผลงาน

หน้า `admin.html` ให้กรอกรหัสผ่าน `1234` ก่อนใช้งานเพิ่มและลบผลงาน โดยแต่ละงานเพิ่มรูปได้ 1–3 รูป (รูปละไม่เกิน 10 MB) และสามารถใช้ปุ่มลูกศรในรายการผลงานเพื่อเลื่อนลำดับการแสดงได้ เลขงานจะอัปเดตตามลำดับใหม่ นอกจากนี้เพิ่มลิงก์ผลงาน (ไม่บังคับ) ซึ่งต้องเป็น URL `http://` หรือ `https://` และแนบไฟล์ PDF (ไม่บังคับ) ขนาดไม่เกิน 10 MB ได้ ผู้ชมสามารถเปิด PDF จากหน้าผลงานได้

ผลงานที่เพิ่มในหน้าแอดมินจะเก็บใน IndexedDB ของเบราว์เซอร์เครื่องนี้เท่านั้น จึงยังไม่แสดงให้ผู้ชม GitHub Pages เห็นโดยอัตโนมัติ หลังจากเพิ่มหรือจัดเรียงผลงานแล้ว:

1. เข้าหน้า `admin.html` จากเบราว์เซอร์เครื่องที่มีผลงาน แล้วกด **เตรียมไฟล์สำหรับเผยแพร่** จากนั้นกดปุ่มดาวน์โหลด `published-projects.json`
2. ใน GitHub ให้อัปโหลดไฟล์นี้ทับ `published-projects.json` ที่อยู่โฟลเดอร์เดียวกับ `work.html` แล้ว commit การเปลี่ยนแปลง
3. รอให้ GitHub Pages เผยแพร่การเปลี่ยนแปลง จากนั้นเปิดหน้า `work.html` เพื่อตรวจดู

ไฟล์ที่ส่งออกมีรายละเอียด รูปภาพ และ PDF ที่แนบอยู่ ข้อมูลเหล่านี้จะเปิดให้ผู้เข้าชมเว็บไซต์เห็นได้ อย่าบันทึกข้อมูลลับลงในผลงาน ไฟล์นี้ใช้ได้กับเว็บไซต์ static โดยไม่ต้องมีเซิร์ฟเวอร์ แต่การแก้ไขในหน้าแอดมินครั้งถัดไปต้องส่งออกและอัปโหลดใหม่ทุกครั้ง

รหัสผ่านหน้าแอดมินตรวจสอบด้วย JavaScript ฝั่งเบราว์เซอร์ จึงเป็นเพียงการซ่อนหน้า ไม่ใช่การป้องกันจริง ผู้ที่เข้าถึงเว็บไซต์สามารถตรวจดูโค้ดและข้ามการตรวจสอบได้ หากต้องการควบคุมสิทธิ์จริงหรือแก้ไขข้อมูลออนไลน์โดยไม่ต้องเผยแพร่เว็บใหม่ ต้องใช้ backend พร้อมระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์
