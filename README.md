# Portfolio ของนายธาวิน เดชวัฒน์

เว็บไซต์ Portfolio แบบ static ภาษาไทย สร้างด้วย HTML, CSS และ JavaScript แบ่งเป็น 3 หน้าแยกกัน รองรับหน้าจอมือถือและเดสก์ท็อป

## เปิดใช้งาน

เปิด Terminal ในโฟลเดอร์ `assets` แล้วรัน local server (หน้าแอดมินใช้ JavaScript modules และ IndexedDB):

```powershell
python -m http.server 5500
```

จากนั้นเปิด `http://localhost:5500` โดยแต่ละหน้าจะอยู่ที่:

- `index.html` — หน้าแรก
- `work.html` — ผลงาน
- `about.html` — ประวัติส่วนตัว
- `admin.html` — จัดการ/อัปโหลดผลงาน

## ปรับแต่งหน้าเว็บ

- แก้ชื่อและข้อมูลแนะนำตัว/ประวัติส่วนตัวใน `index.html` หรือ `about.html`
- แก้ข้อมูลผลงานในการ์ด `.project-card` ใน `work.html`
- ปรับสีและการจัดวางใน `style.css`
- แบนเนอร์แนวนอนด้านบนหน้าแรกใช้ไฟล์ `รูป/รูปโปร.png` โดยกำหนด `src` ของ `.home-banner img` ใน `index.html`
- ภาพในกรอบโปรไฟล์ใช้ไฟล์ `รูป/เอง.jpg` ทั้งหน้าแรกและหน้าประวัติส่วนตัว หากเปลี่ยนรูป ให้อัปเดต `src` ของ `.avatar-art img` ใน `index.html` และ `about.html` โดยกำหนดตำแหน่งครอปใน `style.css`

## หน้าแอดมิน

หน้า `admin.html` ให้กรอกรหัสผ่าน `1234` ก่อนใช้งานเพิ่มและลบผลงาน โดยแต่ละงานเพิ่มรูปได้ 1–3 รูป (รูปละไม่เกิน 10 MB) และสามารถใช้ปุ่มลูกศรในรายการผลงานเพื่อเลื่อนลำดับการแสดงได้ เลขงานจะอัปเดตตามลำดับใหม่ นอกจากนี้เพิ่มลิงก์ผลงาน (ไม่บังคับ) ซึ่งต้องเป็น URL `http://` หรือ `https://` และแนบไฟล์ PDF (ไม่บังคับ) ขนาดไม่เกิน 10 MB ได้ ผู้ชมสามารถเปิด PDF จากหน้าผลงานได้ รหัสนี้ตรวจสอบด้วย JavaScript ฝั่งเบราว์เซอร์ จึงเป็นเพียงการซ่อนหน้าจอ ไม่ใช่การป้องกันจริง ผู้ที่เข้าถึงเว็บไซต์สามารถตรวจดูโค้ดและข้ามการตรวจสอบได้ ข้อมูลยังเก็บใน IndexedDB ของเบราว์เซอร์เครื่องและ origin ปัจจุบันเท่านั้น ไม่ได้อัปโหลดไปเซิร์ฟเวอร์ หากเผยแพร่เว็บไซต์สาธารณะและต้องการความปลอดภัยจริง ต้องใช้ backend พร้อมระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์
